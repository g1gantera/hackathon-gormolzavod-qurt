# Qurt promo — Гормолзавод

Демонстрационный сайт для AI Design Hackathon 2026. Вдохновлён структурой kz.snickersni-promo.com; оформление, тексты и материалы адаптированы под Гормолзавод.

## Запуск

```sh
npm start
```

Открыть http://localhost:5173. Сборка и npm-зависимости не требуются, нужен Python 3. Для проверок нужен Node.js 20+ (браузерный сценарий использует встроенный WebSocket Node.js 22+).

## Публикация на GitHub Pages

GitHub Pages публикует содержимое папки `docs/` в корне репозитория из ветки `website/promo-demo`. Источник публикации — **Deploy from a branch**, папка — **`/docs`**. При обновлении сайта скопируйте содержимое `website/dist/` в `docs/`, затем отправьте изменения в эту ветку. Адрес сайта появится в **Settings → Pages** после публикации.

## Возможности

- Адаптивная главная страница с пеналом 120 г, шагами участия, концепциями подарков, продуктом и FAQ.
- Русский и казахский интерфейс.
- Демо-регистрация, локальный кабинет, история кодов, прогресс до наград.
- Тестовые коды QURT-DEMO-001 — QURT-DEMO-005, защита от повторного ввода в одном локальном профиле.
- Согласие на локальное хранение, просмотр условий и удаление профиля.

## Границы демо

Это не действующая акция. Нет сервера, SMS, настоящей авторизации, общей базы покупателей, реальных призов и проверки кодов с настоящих упаковок. Используйте вымышленные данные. Имя, город, возрастная группа, маска телефона, время согласия и история кодов хранятся только в localStorage. Полный телефон не сохраняется. Очистка localStorage сбрасывает профиль, поэтому это не защита от мошенничества в настоящей акции.

Сроки, призы и пороги не утверждены. Стикер, кружка и керамическая баночка — иллюстрации механики. Упаковка и изображения созданы с AI; пищевой контакт и герметичность материалов требуют производственной проверки. QR на изображениях не является рабочим промокодом.

## Проверки

```sh
npm run check
```

Браузерная проверка: запустить сайт на 5173 и отдельный Chrome с CDP-портом 9226, затем `node tests/browser-qa.mjs`. Проверяет регистрацию, неверный и повторный код, уровни наград, перевод, мобильный размер и удаление профиля. Скриншоты пишет в /tmp.

## Материалы

Логотип извлечён из предоставленного ТЗ. Шрифт Open Sans (SIL Open Font License). Изображения пенала и керамики — ранее согласованные AI-концепции. Hero — отдельная AI-визуализация пенала на прозрачном фоне. Файлы опубликованного сайта находятся в dist/.

## Presentation update

The public interface uses clean promotional copy without demo badges and guidance banners. The implementation remains browser-local; no backend, SMS verification, real prize fulfillment, or customer database was added. The example code is shown only in the code-entry field. q.club mug and sticker-pack imagery was generated for this revision. Prize cards keep images above descriptions at all viewport sizes.
