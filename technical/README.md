# Технические материалы упаковки

- [final_bar_60g/](final_bar_60g/README.md) — **выбранный окончательный вариант 60 г**: 14-страничный PDF, точные SVG лицевой и оборотной сторон, предварительная схема конструкции, визуализация, данные ТЗ, рабочий QR демосайта, спецификация и запрос производства.
- `carton_120g/` — ранний технический и дизайнерский комплект картонной упаковки.
- `vacuum_120g/` — комплект прямоугольного вакуумного пакета: PDF, SVG, PNG, данные маркировки, спецификация, кандидаты на производство и промпты.
- `upload_manifest.json` — контрольные SHA-256 скопированных файлов.

Все визуальные варианты перечислены в [каталоге sketch](../sketch/README.md).

Это рабочие материалы для согласования, не разрешение на печать. Состояние незавершённых пунктов приведено в README и PDF соответствующего комплекта. Архивы ZIP, промежуточные страницы проверки и копии страниц сайтов не дублируются в репозитории.
